# TermBeacon 品牌页头设计

## 目标

优化左侧栏顶部的品牌区域：移除“CLI Agent 工作台”副标题，只保留 TermBeacon 名称，并以抽象信标 Logo 建立简洁、专业的视觉识别。

## 设计方案

- 使用内联 SVG 绘制抽象信标：中心光点与两段向外扩散的信号弧线，呼应 Beacon 的产品含义。
- Logo 收进轻微圆角的方形底座，采用克制的冷蓝色层次与细边框，不使用强烈发光、AI 星星或机器人元素。
- Logo 视觉尺寸为 28–32px，与右侧新建终端按钮对齐。
- 品牌名仅显示“TermBeacon”，适度提升字重和字号，保持现有界面的克制风格。
- 深浅主题沿用现有 CSS 变量，保证对比度和协调性；窄侧栏下保持品牌名称可见且不挤压操作按钮。

## 实现范围

仅修改 `src/renderer/App.tsx` 的品牌区域及 `src/renderer/styles.css` 的相关样式，增加一个局部 SVG 图标组件。不改动终端、工作区、状态检测或其他交互功能。

## 验证

运行 `npm test` 和 `npm run build`，并检查深浅主题及窄侧栏下的页头布局、SVG 显示与新建终端按钮对齐。
