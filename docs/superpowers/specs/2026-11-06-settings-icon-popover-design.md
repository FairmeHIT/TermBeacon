# 设置图标与浮层遮挡修复设计

## 目标

让设置入口与侧栏现有线性图标风格协调，并确保设置浮层不会被侧栏边界裁切。

## 设计

1. 将齿轮 SVG 替换为三行滑块 SVG，保留现有按钮、尺寸、描边、悬停及选中样式。
2. 将设置浮层从侧栏 DOM 中移到应用根布局下，避免受到 `.sidebar { overflow: hidden; }` 的裁切。
3. 浮层继续使用绝对定位，贴近侧栏左下方，并随现有侧栏宽度调整。保留全部设置内容、状态和交互，不改动设置行为或侧栏宽度逻辑。

## 验证

- 打开设置后，浮层完整可见，不被工作区覆盖。
- 深浅主题下图标与浮层显示正常。
- 调整侧栏宽度后，浮层位置仍合理。
- TypeScript 与 Vite 构建通过，现有自动化测试通过。

## 范围限制

仅修改设置图标、浮层挂载位置及其必要样式，不进行无关重构。
